Workflow d'Analyse

Découvrez le processus complet d'analyse de données du portail Client Analytics.

Préparation des Données

Upload ou Sélection

Commencez par uploader votre fichier Excel ou sélectionnez un dataset de démonstration. Le système accepte les formats .xlsx et .xls jusqu'à 10MB.

  • Upload de fichiers Excel
  • Sélection de datasets démo
  • Réutilisation de datasets existants

Overview du Dataset

Exploration Initiale

Visualisez les informations générales de votre dataset :

  • Dimensions : Nombre de lignes et colonnes
  • Types de données : Numériques vs Catégorielles
  • Valeurs manquantes : Identification des données incomplètes
  • Statistiques descriptives : Moyennes, médianes, écarts-types
  • Aperçu des données : Premières lignes du dataset

Analyse Statistique

Visualisations Interactives

Explorez vos données avec des visualisations Plotly interactives :

  • Histogrammes : Distribution des variables numériques
  • Graphiques en barres : Fréquences des variables catégorielles
  • Heatmap de corrélation : Relations entre variables numériques
  • Sélection de variables : Analyse globale ou variable spécifique

Modélisation Machine Learning

Prédiction Automatisée

Entraînez des modèles de Machine Learning sans coder :

Classification
  • Logistic Regression
  • Random Forest Classifier
  • Métriques : Accuracy, F1-Score, Matrice de confusion
Régression
  • Linear Regression
  • Random Forest Regressor
  • Métriques : RMSE, R², MSE
Preprocessing Automatique
  • Imputation des valeurs manquantes
  • One-Hot Encoding pour variables catégorielles
  • Standardisation des variables numériques
  • Séparation Train/Test automatique

Clustering K-Means

Segmentation Automatique

Découvrez des groupes naturels dans vos données :

  • Algorithme K-Means : Clustering non supervisé
  • Nombre de clusters : Ajustable de 2 à 10
  • Standardisation : Optionnelle pour normaliser les échelles
  • Visualisation PCA : Projection 2D des clusters
  • Métriques : Inertia, Silhouette Score
  • Centroids : Caractéristiques moyennes par cluster

Interprétation et Export

Outputs Exploitables

Récupérez les résultats pour vos analyses :

  • Export CSV : Dataset avec labels de clusters
  • Visualisations : Graphiques interactifs Plotly
  • Métriques : Performances détaillées des modèles
  • Feature Importance : Variables les plus influentes
